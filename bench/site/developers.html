Information for developers

We are piloting a small booking availability API for partner apps and AI assistants. This page explains what is published and how to request access.

What is available

The pilot API returns free appointment slots by clinic and appointment type. It does not return any patient information, and making a booking still requires the patient to confirm by phone or email.

Discovery files

Our API catalogue is published at /.well-known/api-catalog in the linkset format. A plain-language summary of the website for AI assistants is published at /llms.txt.

Requesting access

Email developers@harbourline.example with the name of your application, how you will use the data and an expected request volume. Access is free during the pilot. We review requests within ten working days.

Fair use

Please cache availability for at least five minutes and do not make more than one request per second. We may suspend keys that exceed these limits without notice.

Versioning and changes

The pilot API is versioned in the URL. We give at least ninety days’ notice by email before retiring a version, and we announce new fields on this page. During the pilot we may change response formats after giving thirty days’ notice to registered developers.

Data and privacy

The availability API never exposes patient names, contact details or clinical information. Appointment requests made through partner applications are treated exactly like requests from our own booking form: a receptionist confirms the details with the patient before anything is booked. We log API requests for thirty days for security monitoring and then delete them.
